# Titanic: 객실 정보의 추가 가치와 분류 기준 비교

학회와 강의에서 접한 모델링 과정을 직접 확인하기 위해 Kaggle Titanic 데이터를 분석한 개인 프로젝트입니다.
891명의 학습 데이터를 바탕으로, 변수의 의미를 확인하고 비교 결과에 따라 다음 질문을 정하는 과정을 기록했습니다.

**핵심 질문은 두 가지였습니다.**

1. 객실 위치가 생존과 관련 있다면, 승객 등급 외에 예측 정보를 더 줄 수 있을까?
2. 생존자를 더 맞히는 분류 기준은, 사망자 오분류까지 고려해도 개선이라고 볼 수 있을까?

## 질문에서 후속 실험까지

| 질문·관찰 | 확인한 내용 | 다음 판단 |
|---|---|---|
| 여러 객실이 적힌 기록을 하나로 대표해도 될까? | 공백이 있는 Cabin 24행을 추출해 복합 표기를 확인. 같은 문자에 여러 번호가 붙은 사례와 `F G73` 같은 표기가 함께 존재 | 실제 인접성은 확정하지 않고, 첫 문자를 Deck으로 사용하는 제한적인 규칙을 명시 |
| Deck과 Pclass는 얼마나 겹칠까? | A·B·C로 분류된 승객은 모두 1등급. 같은 등급 안에서도 Cabin 기록 유무에 따른 생존율 차이가 관찰됨 | 생존율 차이와 예측 정보의 추가 가치를 구분해 비교 |
| 객실 변수를 더하면 나아질까? | AgeGroup 기준 모델의 평균 CV 정확도 0.818185 → CabinKnown·Deck 추가 시 0.812567 | 이번 조건에서는 두 객실 변수의 추가로 평균 정확도가 높아지지 않았다고 해석 |
| class weight 적용 후 기준을 더 낮추면 어떨까? | balanced 모델에서 0.50 → 0.45: 생존자를 11명 더 맞히지만 사망자 오분류도 20명 증가 | recall 상승만으로 개선이라 판단하지 않고 오류의 종류와 수를 함께 비교 |

## 비교 조건과 해석 범위

- 02~04는 5-fold Stratified CV(`shuffle=True`, `random_state=42`)를 사용합니다.
- 학습이 필요한 결측 대체와 인코딩·표준화는 Pipeline 안에서 처리합니다.
- **AgeGroup 결측 처리에는 단계 간 차이가 있습니다.** 02는 `Unknown` 범주, 03·04는 학습 fold의 최빈값을 사용합니다. 각 노트북 안의 비교를 해석하며, 단계 간 점수 차이를 한 요인의 효과로 설명하지 않습니다.
- 객실 기록의 생존율 차이는 관찰된 관계입니다. 객실 위치의 인과적 효과나 실제 인접성을 확인한 것은 아닙니다.
- 같은 CV와 제출 점수를 보며 후보를 선택했으므로 독립적인 최종 성능 평가로 제시하지 않습니다.

## 본인 역할과 AI 활용

분석 질문과 일부 후속 실험을 직접 정했습니다. 객실 정보가 승객 등급 외에 무엇을 더 알려 주는지,
여러 객실 기록을 어떻게 대표할지, 생존자를 더 맞히는 변화가 다른 오류까지 고려해도 개선인지 질문했습니다.
구현·검증 방법과 결과 해석 점검은 AI의 도움을 받아 진행했습니다.

## 실행

```bash
pip install -r requirements.txt
jupyter lab
```

[데이터 준비 안내](data/README.md)에 따라 `data/train.csv`, `data/test.csv`를 준비한 뒤,
각 노트북을 새 커널에서 위부터 실행합니다. 노트북끼리 실행 상태를 공유하지 않습니다.
04의 새 제출 파일은 `submissions/`에 저장됩니다(Kaggle에서는 `/kaggle/working/submissions/`).
